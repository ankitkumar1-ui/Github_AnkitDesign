# ADX onboarding prototype

Clickable prototype: Sign in → About you → Connect your data → Your goals (opens with Cortex setting up) → Home → ADX Setup overview → Connections → Web Signals site map → Signals. Customer Profiles and Product Catalog are in the side menu.

```bash
npm run dev   # http://localhost:5173
```

See CLAUDE.md for the file layout and the template syntax used in `screens/`.
